Tecno Tech Oberá — Catálogo para GitHub Pages
Este paquete conserva los 603 productos del archivo products.json recibido y las imágenes disponibles en assets/.
Publicar en GitHub Pages
Extraé el ZIP en tu celular o computadora.
En el repositorio de GitHub, subí index.html, products.json, la carpeta assets/ y, si querés conservar el catálogo descargable, catalogo.pdf.
Dejá index.html y products.json en la raíz del repositorio, no dentro de otra carpeta.
En GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.
Funciones incluidas
Diseño adaptable a celular y escritorio.
Búsqueda por nombre, descripción, categoría y precio.
Filtro por proveedor/categoría y orden alfabético.
Carrito y creación de pedido para WhatsApp.
Administración local para agregar, editar y eliminar productos.
Importar/exportar products.json.
Importante
El catálogo incluye 603 productos y 576 referencias de imagen; los archivos de imagen existentes están en assets/.
El número de WhatsApp se configura en index.html, variable WHATSAPP_NUMBER (actualmente 5493755223737). Cambialo si el número de pedidos debe ser otro.
El PIN inicial del panel es 1234, definido en ADMIN_PIN. Cambialo antes de publicar, pero recordá que en una web estática el PIN del código no es una protección real.
Los cambios del panel se guardan solo en el navegador/dispositivo que los realiza. Para que los vea todo el mundo, descargá el products.json actualizado desde el panel y reemplazá el archivo del repositorio en GitHub.
Los precios y descripciones se conservan tal como estaban en products.json. Confirmar precio y stock antes de la venta.
